\# PocketPay



PocketPay is a digital wallet application designed to simulate secure domestic financial transactions in India.



\## Technology Stack



\- \*\*Backend:\*\* Java 21, Spring Boot

\- \*\*Frontend:\*\* Angular (planned)

\- \*\*Database:\*\* MySQL

\- \*\*Security:\*\* Spring Security, JWT, Argon2

\- \*\*Database Migration:\*\* Flyway

\- \*\*Build Tool:\*\* Maven

\- \*\*Architecture:\*\* Modular Monolith



\## Project Status



Under active development.



\## Disclaimer



PocketPay is an educational and portfolio project. It is not a licensed financial service and does not process real money.
